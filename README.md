# GMTK2025
A small game created in 72 hours for GMTK 2025, music by Eric the Funny Baron and background art made by a teammate.

Roboloop is a timing-based puzzle game where you play as Cam, a robot with a camera for a head, who is trapped in a factory that loops. Whether it's pistons moving back and forth, a rocket spinning around your key, or more, Roboloop is a game I hope you can enjoy. So then player, can you get past all 23 levels in a game where everything but you is trapped in a loop?

Controls:

W/A/S/D or Arrow keys to move

R or Backspace to restart the level

(Currently, the only way to go back to the main menu is to complete the last level or reload the page.) There was a pause menu, but that broke last minute, so I had to remove it.)

All levels are unlocked from the get-go, so if you get stuck on a level, you are more than welcome to reload your page, launch the game, and just skip it.

If you get stuck, here's a hint: anywhere there is a vent is a safe spot you can stand without dying!
